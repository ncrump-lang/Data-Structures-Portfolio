## Project 1: NBA Team Peformance Analysis 

Research Question

How are three-point shooting, rebounding, assists, and turnovers associated with an NBA team's regular-season win percentage?

Project Overview 

This project examines whether selected NBA team performance statistics are associated with regular-season success. The analysis focuses on three-point shooting percentage, rebounds, assists, and turnovers and their relationship with team win percentage.

Data 

The dataset contains 716 NBA team-season observations covering the 2000-01 through 2023-24 regular seasons. The data was obtained from Kaggle using the Kaggle API. 

Analysis 

The project includes data cleaning and preparation, visualizations, and analysis of the relationships between team performance statistics and regular-season win percentage.
